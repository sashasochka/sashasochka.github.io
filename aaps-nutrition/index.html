AAPS nutrition link

This page is only a fallback. When AndroidAPS is installed with the nutrition-link feature and the link is verified, Android opens the app directly.

Nothing on this page is uploaded. The meal data lives in the part of the address after #, which browsers never send to the server. No food image is loaded automatically.

If you opened this from a chat app and expected AndroidAPS to open, use that app's “Open in browser” or “Open in external app” option. An in-app browser can keep the link to itself.
